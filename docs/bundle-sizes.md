Generated by `node scripts/bundle-sizes.mjs` after `npm run build`. Sizes are the raw and gzip-9 compressed bytes of each ESM bundle file in `dist/` — what your bundler will pull in for an `import` from each subpath. Per-subpath ceilings are enforced by `npm run size`.

> **Notes**
>
> - The root `voidframe-ui` import is the legacy monolithic surface. Bundler consumers (Vite / Webpack / Next.js / Remix) tree-shake it; bundler-free consumers (Deno / Bun / esm.sh / unpkg / `node --input-type=module`) should import from a category subpath instead.
> - Optional peers (`d3-*`, `dompurify`, `topojson-client`, `react-live`, `jsbarcode`, `qrcode-generator`) are not included in any subpath's bytes — they're declared as `peerDependenciesMeta.*.optional: true` and resolved at the consumer.
> - The stylesheet is shipped once as `voidframe-ui/styles.css`; every subpath consumes the same CSS file.
