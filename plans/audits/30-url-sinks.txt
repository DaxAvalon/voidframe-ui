── safeHref allowlist (src/utils/safeHref.ts) ───────────────
Accepts: http:, https:, mailto:, tel:, sms: + relative prefixes "/", "./", "../", "?", "#".
Whitespace/control-char-prefixed schemes are normalized away before dispatch (line 55).
Bare-host strings ("example.com/foo") pass through as relative — browsers will not execute them
as `javascript:` because the colon (if any) is no longer a scheme separator. Verified safe.
Unsafe URLs return fallback `"#"` (configurable). Returning "" on empty input passes through unchanged
(consumers use "" as a no-op). data: / blob: are rejected by default.
