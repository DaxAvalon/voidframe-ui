# Controlled/uncontrolled pattern audit (plan 29, task 4)
# Pattern key (order: value, defaultValue, onChange, onValueChange):
#   V = value present         - = absent
#   D = defaultValue present
#   C = onChange present
#   VC = onValueChange present
#
# Canonical patterns the plan calls out as "good":
#   VDC-    value+defaultValue+onChange
#   VDCVC   value+defaultValue+onChange+onValueChange (text inputs)
#   VD--    display-only (value + fallback, no setter)
#   -DC-    uncontrolled with default + onChange
#   ---VC   value-emit only
#
# Deviations flagged below.

## Deviations summary (needs Findings §4 entries)
# DEV-01 Input/Textarea/SearchInput/PasswordInput: V-CVC — no defaultValue exposed
#        Real components accept `defaultValue` via native HTML spread, but
#        it is not in the typed public API. Adds uncontrolled friction.
# DEV-02 MenuRadioGroup: V-VC — missing defaultValue
# DEV-03 Select: V-C- — missing defaultValue
# DEV-04 Slider: V-C- — missing defaultValue
# DEV-05 NumberInput: V-C- — missing defaultValue
# DEV-06 Checkbox/Switch/Toggle: use `checked`/`defaultChecked` instead of
#        `value`/`defaultValue`. This is a DIFFERENT naming convention.
# DEV-07 CheckboxGroup: `values`/`onChange(values)` — should be `value` +
#        `onValueChange(values)` per canonical.
# DEV-08 Tabs: `activeKey` / `onChange(key)` — should be `value` +
#        `onValueChange(key)` per canonical.
# DEV-09 Pagination: `page` / `onChange(page)` — should be `value` +
#        `onValueChange(page)`.
# DEV-10 List editors (ReorderList, Sortable, FileUpload, EnvironmentVars,
#        KeyValueEditor): `items` / `onChange(next)` — different noun per
#        component, no canonical `value`.
# DEV-11 FilterBuilder: mixes `defaultValue` + `onValueChange` but the
#        value-emit vocabulary is `rules` (inside type).
# DEV-12 CommandInput: `defaultValue`/`value`/`onValueChange` + a separate
#        `onSubmit(command)` — fine, two-channel.
# DEV-13 Composer: `value`/`defaultValue`/`onChange(next)` but also `onSubmit`
#        and `onStop`. Classify canonical.
